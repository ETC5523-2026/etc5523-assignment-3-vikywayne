# Vikash Manoj | The Data Journal

This repository contains my personal website and data blog, developed for ETC5523 Communicating with Data at Monash University using [Quarto](https://quarto.org/).

**Author:** Annamalai Vikash Raam Manoj

**Website:** https://etc5523-2026.github.io/etc5523-assignment-3-vikywayne/

**GitHub:** [https://github.com/vikywayne](https://github.com/vikywayne)

## About the blog

The blog is intended for students, analytics practitioners, and general readers interested in understanding how data can be used to investigate real-world questions. It focuses on data analysis, visualisation, and communicating evidence clearly, using examples such as healthcare data and public health outcomes.

## Built with

- Quarto
- R and data visualisation tools
- HTML and CSS
- GitHub and GitHub Pages
